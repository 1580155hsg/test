# GitHub workflow practice

This repository is a public sandbox for learning GitHub issues, branches,
pull requests, merges, and profile achievements. Practice changes belong here
so that exercises do not create noise in other projects.

## Workflow

1. Create a branch for one small change.
2. Make a useful documentation or example change.
3. Open a pull request and inspect its diff.
4. Merge when the change is ready, then delete the branch.

See [the collaboration guide](docs/collaboration.md) for author attribution,
review choices, and a completion checklist.

## Scope

Achievement exercises are intentional practice. GitHub controls badge
eligibility and processing, so completing an exercise does not guarantee
that a badge appears immediately. Do not post practice issues or pull
requests to unrelated projects.
